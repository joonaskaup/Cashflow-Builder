This **Mac app preview** replaces the loose launcher/Python folder with a self-contained **Cashflow Builder.app**.

It is locally signed, **not Apple-notarized**. The browser-download first-open check must be confirmed before treating this as a general release. It is deliberately marked as a prerelease.

### Download and open

Download **Cashflow-Builder-0.2.0rc1-macos-arm64-app.zip**, unzip it, move **Cashflow Builder.app** to Applications or another permanent location, and open it. Requires an Apple silicon Mac with macOS 12 or later. The interface opens in your browser. No Python installation or Terminal window is required.

macOS may require **System Settings → Privacy & Security → Open Anyway** for Cashflow Builder.app. Approve it only if you choose to trust this download. If individual Python components still trigger prompts, stop and report the warning. Do not disable Gatekeeper or remove quarantine to make the acceptance test pass.

### What changed

- Python, libraries and the planner are contained in one app bundle, with nested code signatures checked.
- Clicking the Dock icon reopens the planner. Quit reminds you to save; Stop app also closes the Mac app.
- Projects have a permanent location outside the application: `~/Library/Application Support/Cashflow Builder/Projects`.
- The start page includes an Open Projects folder button and migration instructions.
- The app retains its local network sandbox. It does not upload budget files.

### Existing projects

Save and stop your old folder version first. Keep its Projects folder as a backup. In the new app choose **Open Projects folder**, then stop the app and copy the individual old project folders into that location. Keep existing project folders; do not overwrite a same-named folder. Reopen the app and check the saved plan. There is no need to import the original budgets again.

For subsequent .app updates, save and quit, then replace only Cashflow Builder.app. Projects stay in their separate folder. The old `.command` updater is for the old folder distribution only.
