Cashflow Builder imports an existing FFF budget, helps you place costs on a timeline, and writes the plan into the FFF cashflow sheet in your working budget workbook.

This is the first public release, for **Apple silicon Macs**.

### Download

Download **Cashflow-Builder-0.1.0-macos-arm64.zip**, unzip it, and double-click **Start Cashflow Builder.command**. Keep the whole folder together. Python and the required libraries are included. GitHub's automatic “Source code” archives are for development and do not include the runtime.

### Included

- Click payment months, enter percentages, and plan several costs at once.
- Link costs to preparation, shooting, wrap and named milestones.
- Split budget days or months between periods, with one part taking the remainder.
- Create installment rows and assign each cost its own shares.
- Refresh revised budget figures while retaining timing for matched costs.
- Export the FFF cashflow and an Excel report of work dates and payments.
- Open **Help** for the complete offline guide, including worked examples and refresh instructions.

The [user guide](https://github.com/joonaskaup/Cashflow-Builder/blob/v0.1.0/docs/USER_GUIDE.md) explains which dates follow production changes and which stay fixed.

### Updating an existing copy

Save your work and stop the app. Unzip this release into a separate folder, run **Update existing Cashflow Builder.command** from the new download, and select your existing app folder. Launch from that existing folder afterwards. The updater preserves Projects and backs up the previous app code. Back up your whole Projects folder separately.

### Compatibility and checks

Requires a supported FFF workbook layout and Excel-calculated formula values. Work and payment dates are distinct; fixed payment months do not follow later changes to production periods. Review weekday estimates and month-only dates before using the report for agreements.

The app runs locally. The download contains only app files, dependencies and a fictional example, with no production projects or private budgets. This folder-based macOS package is not signed or notarized. Intel Mac and Windows packages are not included.

Validated with 97 Python tests, 43 JavaScript tests, and a packaged-app launch/import/refresh/report check. A SHA-256 checksum accompanies the download.
