Updating an existing budget

Use Refresh budget inside your project to update the cost breakdown while keeping saved timing.

Updating figures, quantities and rows — step-by-step guide

How to refresh without starting over
  1. Open your project and save any pending payment or date edits.
  2. Choose Open cashflow workbook. Edit the budget figures in this working copy in Excel.
  3. Save and close the Excel workbook, then click Refresh budget in the app.
  4. Review new or changed costs. Existing costs keep their timing when the app can match them; substantial row changes may need your review.

Percentage allocations follow the new budget amount. Fixed euro amounts may need adjusting.

The project uses its own working copy. Editing the original file you imported does not update this project automatically.

Start a new cashflow

Choose an FFF budget in Excel format. We make a working copy with its own dates, timing patterns and extracted Erittely list.

Your original file is unchanged. Existing manual financing is retained. Existing cost allocations in the cashflow are kept in the original copy; planning starts with untimed costs.

Ready to check and copy

The month is taken from the workbook when available. Keep it unchanged if financing has already been entered.

Source columns and worksheet names

Defaults match the FFF template. The original cashflow layout must have cost rows 21–40, total row 41 and closing balance row 42.

What happens next

1. Check that every extracted cost matches the budget total.
2. Set production dates in the planner.
3. Select costs, assign timing and Save to the working copy.

Close this app’s Terminal window or use Stop app when finished. Save your work first. Reopen with Start Cashflow Builder.command.
